# AGT-001 / AGT-003：Codex 命令审批

## 用户场景

用户从 Agent 首页选中工作区，使用已配置的 Codex 连接创建会话并发送消息。Codex 准备
执行一条需要额外权限的命令时，Trowel 显示原生 command approval：命令、工作目录、
原因和原生可选决定都属于当前 request，而不是模型生成的一段普通文字。

在用户决定前，当前 turn 保持等待，不能再发送第二轮。用户选择取消后，决定必须使用
同一个原生 request ID 回给 app-server，当前轮次随后形成明确终态。审批消失、普通文本
冒充审批、决定送错会话、重复执行命令或关闭后仍残留资源，都算失败。
