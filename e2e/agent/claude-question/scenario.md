# AGT-001 / AGT-003：Claude 会话与结构化提问

## 用户场景

用户从 Agent 首页选中一个真实存在的工作区，选择已经配置好的 Claude Code 连接并创建
会话。消息发出后，Claude 不是在普通输入框里随口追问，而是通过 AskUserQuestion 暂停
当前轮次。界面应展示原生问题和选项，输入框在等待期间不能偷偷启动第二轮。

用户选择一个答案后，答案回到原来的 request，原轮次继续并正常结束。UI 中的 live
结果、服务端保存的会话身份和资源账本必须指向同一轮。关闭会话后该 session 的资源为
零，最终退出 App 后全部资源为零。提问被吞掉、回答错 request、自动另开一轮或留下
悬挂 turn，都算失败。
