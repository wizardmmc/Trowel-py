# DIS-003 / DIS-004：进程中断后恢复同一轮，再停止并删除

## 用户场景

三位参与者正在回答同一轮：一位已经成功，另外两位只留下未完成的旧 attempt。Trowel
进程突然中断，没有机会走正常退出清理。应用用同一隔离数据根重新启动后，应恢复原来的
逻辑轮：成功槽位不重跑，另外两位各建一次新 attempt，旧 partial 永远不能进入共同公开。

三位新旧状态收敛后只共同公开一次。用户随后停止研讨并确认删除；停止必须先关掉全部
participant 资源，删除后历史列表不再出现这场研讨。重跑成功槽位、复用旧未完成 attempt、
公开旧 partial、重复发布、未关资源就删除或最终 App 退出不归零都算失败。
