# 产品 North Star

Trowel 是跨会话持续存在的本地 AI 工作系统。它托管原生 agent 会话，把经过验证、可追溯的信息沉淀为长期记忆，并在之后的工作中重新提供相关上下文。

## 用户价值

- 会话可以恢复、观察和审计，不因切换模型或上下文而丢失工作现场；
- 记忆来自真实会话和明确证据，能说明来源、有效性和不确定性；
- 多个使用不同模型连接的 Agent 可以在同一研讨中平等交换判断、保留分歧，并把
  可追溯的讨论现场交给普通 Agent 会话继续处理；
- tcc、复习卡片和知识花园服务同一套本地数据，不要求把私人内容上传到额外平台；
- 自动工作受预算、权限和等待条件约束，不能把模型自述当成现实事实。

## 产品边界

- 以单用户、本地优先为前提；
- 复用 Claude Code 与 Codex 的原生能力，不重新发明通用 coding agent；
- 多方研讨的轮次和停止规则由 Trowel 确定性执行，不把某一个参与模型设为默认主控；
- 机制保持稳定，模型、阈值、prompt 和调度权重可以迭代；
- 产品正确性优先于训练流程和展示性架构。
